# Λογαριασμοί χρηστών και πρόσβαση — Οδηγός λειτουργίας

Οδηγός για όποιον διαχειρίζεται την εγκατάσταση. Καλύπτει τη σύνδεση, τη δημιουργία λογαριασμών, την αλλαγή κωδικών και την ανάκτηση πρόσβασης αν χαθεί ο κωδικός του διαχειριστή.

Κάθε endpoint του API απαιτεί συνδεδεμένο χρήστη. Δεν υπάρχει ανώνυμη πρόσβαση ούτε κοινόχρηστος λογαριασμός.

---

## 1. Ρόλοι

| Ρόλος | Ετικέτα | Τι μπορεί να κάνει |
|---|---|---|
| `ADMIN` | Διαχειριστής | Τα πάντα, συμπεριλαμβανομένης της διαχείρισης λογαριασμών |
| `SUPERVISOR` | Επόπτης | Όλες τις λειτουργικές εργασίες και τις αναφορές |
| `TECHNICIAN` | Τεχνικός | Όλες τις λειτουργικές εργασίες και τις αναφορές |
| `OPERATOR` | Χειριστής | Όλες τις λειτουργικές εργασίες και τις αναφορές |

Μόνο ο ρόλος `ADMIN` βλέπει το εικονίδιο ρυθμίσεων (⚙) και μπορεί να δημιουργεί, να τροποποιεί ή να διαγράφει λογαριασμούς. Οι υπόλοιποι τρεις ρόλοι σήμερα διαφέρουν μόνο ως προς την ονομασία· καταγράφονται σε κάθε κίνηση για λόγους ιχνηλασιμότητας.

Δώστε στο προσωπικό καθημερινής χρήσης τον ρόλο `OPERATOR` και κρατήστε τον `ADMIN` για τα ένα ή δύο άτομα που διαχειρίζονται το σύστημα.

---

## 2. Σύνδεση

Τόσο η ιστοσελίδα διαχείρισης όσο και η εφαρμογή Android ανοίγουν σε οθόνη σύνδεσης. Η συνεδρία αποθηκεύεται στη συσκευή και διαρκεί 12 ώρες· μετά ο χρήστης συνδέεται ξανά.

Η αποσύνδεση βρίσκεται στο εικονίδιο ρυθμίσεων (⚙) της ιστοσελίδας — ή, για τους μη διαχειριστές, στο κουμπί «Αποσύνδεση» δίπλα στον τίτλο. Στην εφαρμογή Android βρίσκεται στις **Ρυθμίσεις**.

---

## 3. Δημιουργία του πρώτου διαχειριστή

Σε μια νέα εγκατάσταση κανένας λογαριασμός δεν έχει κωδικό, οπότε κανείς δεν μπορεί να συνδεθεί μέχρι να δημιουργηθεί ο πρώτος διαχειριστής. Εκτελέστε την εντολή μία φορά, από τον ριζικό φάκελο του έργου:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production run --rm \
  -e PASSWORD='επιλέξτε-έναν-ισχυρό-κωδικό' \
  migrate npx tsx scripts/set-user-password.ts \
  --username admin --role ADMIN --display-name "Διαχειριστής"
```

Η μεταβίβαση του κωδικού μέσω της μεταβλητής `PASSWORD` — αντί για την παράμετρο `--password` — τον κρατά εκτός του ιστορικού εντολών.

Η εντολή δημιουργεί τον λογαριασμό αν δεν υπάρχει, ή θέτει τον κωδικό του αν υπάρχει ήδη.

Στη συνέχεια συνδεθείτε στην ιστοσελίδα και δημιουργήστε τους υπόλοιπους χρήστες από το περιβάλλον διαχείρισης.

---

## 4. Διαχείριση λογαριασμών από την ιστοσελίδα

Συνδεθείτε ως διαχειριστής και ανοίξτε το εικονίδιο ρυθμίσεων (⚙). Η ενότητα **Χρήστες** βρίσκεται εκεί.

| Ενέργεια | Πώς |
|---|---|
| Δημιουργία χρήστη | **Νέος χρήστης** — όνομα, ρόλος και κωδικός |
| Αλλαγή κωδικού άλλου χρήστη | **Ορισμός κωδικού** στη γραμμή του |
| Αλλαγή του δικού σας κωδικού | **Αλλαγή του κωδικού μου** |
| Απενεργοποίηση χρήστη | **Διαγραφή** στη γραμμή του |

Ο πίνακας δείχνει ποιοι λογαριασμοί μπορούν να συνδεθούν. Όσοι εμφανίζονται ως `Χωρίς κωδικό` υπάρχουν μόνο για να αποδίδονται σε αυτούς παλιές κινήσεις και δεν μπορούν να συνδεθούν μέχρι να τους ορίσετε κωδικό.

### Κανόνες κωδικών

Τουλάχιστον 10 χαρακτήρες, με γράμματα και αριθμούς. Οι ίδιοι κανόνες ισχύουν παντού όπου ορίζεται κωδικός.

### Τι κάνει στην πραγματικότητα η διαγραφή

Ο λογαριασμός απενεργοποιείται και ο κωδικός του διαγράφεται, ώστε να μην μπορεί πλέον να συνδεθεί — αλλά η εγγραφή διατηρείται. Κινήσεις, επισκευές και εγγραφές του μητρώου ελέγχου παραπέμπουν σε αυτήν, και η οριστική διαγραφή θα κατέστρεφε το ιστορικό.

Δύο διαγραφές απορρίπτονται:

- **Ο δικός σας λογαριασμός** — θα κλειδώνατε τον εαυτό σας έξω στη μέση της συνεδρίας.
- **Ο τελευταίος διαχειριστής** — κανείς δεν θα μπορούσε να διαχειριστεί χρήστες μετά. Δημιουργήστε πρώτα άλλον διαχειριστή.

---

## 5. Ανάκτηση χαμένου κωδικού διαχειριστή

Χρησιμοποιήστε την ίδια εντολή της ενότητας 3 με το υπάρχον όνομα χρήστη. Αντικαθιστά τον κωδικό ενός λογαριασμού που ήδη υπάρχει:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production run --rm \
  -e PASSWORD='νέος-κωδικός' \
  migrate npx tsx scripts/set-user-password.ts --username admin --role ADMIN
```

Απαιτείται πρόσβαση στο τερματικό του διακομιστή, και αυτό είναι σκόπιμο: πρόκειται για την έσχατη οδό ανάκτησης, διαθέσιμη μόνο σε όποιον διαχειρίζεται τον διακομιστή.

---

## 6. Ρυθμίσεις

| Μεταβλητή | Σκοπός |
|---|---|
| `JWT_SECRET` | Υπογράφει τα διακριτικά πρόσβασης. Υποχρεωτική στην παραγωγή, τουλάχιστον 32 χαρακτήρες. |
| `JWT_EXPIRES_IN_SECONDS` | Διάρκεια συνεδρίας. Προεπιλογή 43200 (12 ώρες). |

Δημιουργήστε ένα μυστικό με:

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
```

Αντιμετωπίστε το `JWT_SECRET` όπως τον κωδικό της βάσης δεδομένων. Όποιος το κατέχει μπορεί να παράγει έγκυρα διακριτικά για οποιονδήποτε χρήστη. Η αλλαγή του αποσυνδέει τους πάντες — που είναι ακριβώς η σωστή αντίδραση αν υποψιάζεστε ότι διέρρευσε.

---

## 7. Μέτρα προστασίας που ισχύουν

- Οι κωδικοί αποθηκεύονται ως bcrypt hashes και δεν επιστρέφονται ποτέ από το API.
- Η σύνδεση απαντά σε λάθος όνομα χρήστη και σε λάθος κωδικό με τον ίδιο ακριβώς τρόπο και στον ίδιο χρόνο, ώστε να μην μπορεί να ανιχνευθεί ποιο από τα δύο ήταν εσφαλμένο.
- Η σύνδεση περιορίζεται σε πέντε προσπάθειες ανά λεπτό.
- Ο λογαριασμός επανελέγχεται σε κάθε αίτημα, οπότε η απενεργοποίηση ενός χρήστη ισχύει αμέσως και όχι με τη λήξη του διακριτικού του.
- Κάθε endpoint είναι προστατευμένο εξ ορισμού· μια διαδρομή πρέπει να δηλωθεί ρητά ως δημόσια, και μόνο οι έλεγχοι υγείας το κάνουν.

---

## 8. Αντιμετώπιση προβλημάτων

**«Λάθος όνομα χρήστη ή κωδικός»**
Ελέγξτε την ορθογραφία του ονόματος — τα ονόματα χρηστών γράφονται με πεζά. Αν ο λογαριασμός εμφανίζεται ως `Χωρίς κωδικό` στην ενότητα Χρήστες, ορίστε του κωδικό.

**«Πολλές προσπάθειες. Δοκιμάστε ξανά σε ένα λεπτό.»**
Συμπληρώθηκε το όριο προσπαθειών. Περιμένετε ένα λεπτό· καθαρίζει μόνο του.

**Απροσδόκητη αποσύνδεση**
Έληξε η συνεδρία, ή κάποιος διαχειριστής απενεργοποίησε τον λογαριασμό. Συνδεθείτε ξανά· αν αποτύχει, ζητήστε από διαχειριστή να ελέγξει τον λογαριασμό.

**Δεν μπορεί να συνδεθεί κανείς**
Επιβεβαιώστε ότι το backend ξεκίνησε. Αν το `JWT_SECRET` λείπει ή είναι μικρότερο από 32 χαρακτήρες, αρνείται να ξεκινήσει στην παραγωγή και το αναφέρει στα αρχεία καταγραφής:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production logs backend | tail -30
```

**Η εφαρμογή λέει ότι δεν βρίσκει τον διακομιστή**
Η διεύθυνση είναι λάθος ή μη προσβάσιμη — δεν πρόκειται για πρόβλημα διαπιστευτηρίων. Ελέγξτε την από τις **Ρυθμίσεις διακομιστή** στην οθόνη σύνδεσης.
